# 止盈提醒

个人持仓提醒。记下股票、股数、花了多少钱，以及你记得的那个高点。到了止盈、止损、前高、均线破位或单日异动，就发微信叫你处理。

行情来自腾讯公开接口，只做个人提醒，不是投资建议。价格可能有延迟。

不需要单独的数据库。持仓、设置和提醒都写在本机的 `data/db.json`。

## 告警文案

每条都可以在设置里单独关掉。关掉的指标不推送。微信正文是下面这种短句，多条会合成一条消息：

- 止盈提醒：贵州茅台 盈利已达 20%，建议分批止盈
- 止损提醒：贵州茅台 亏损已达 10%，触发止损线
- 前高提醒：贵州茅台 已回到前期高点 2100 附近，注意压力
- 破位提醒：贵州茅台 跌破 5 日线，趋势转弱
- 破位提醒：贵州茅台 跌破 20 日线，趋势转弱
- 异动：贵州茅台 单日涨跌超 5%

句子里的百分比和价格用你当时的实际数字。填了卖出计划时，计划会跟在正文后面。

## 指标

| 指标 | 默认 | 说明 |
| --- | --- | --- |
| 止盈 | 盈利 20% | 到线就建议分批止盈 |
| 止损 | 亏损 10% | 到线就触发止损 |
| 前高 | 高点下方 3% | 回到你填的前期高点附近，或已经站上它 |
| 5 日线 / 20 日线 | 开启 | 现价跌破已经走完的日线。今天这根 K 线不计入均线 |
| 单日异动 | 涨跌 5% | 当天只提醒一次 |
| 回本 | 套牢 8% 后回到成本上下 2% | 曾经亏到套牢线，后来回到成本附近 |
| 自动回撤 | 15% | 没填前高时，从记下之后见到的高点回撤这么多，再涨回才提醒 |

已经跌过一轮的票，把记得的高点填上。没填的话，只会从你记下之后见到的高点算，算不到更早的那一轮。

每只股票可以单独改止盈、止损和前高范围。留空就跟随全局设置。

## 什么时候发

- 交易日 9:15–20:00，每分钟用当天的行情检查一次。
- 同一条止盈、止损、前高、破位或回本，默认 20 小时内不重复。价格回到线外再进来，间隔过了才会再发。
- 单日异动按行情日期只发一次，不套用这 20 小时。
- 每个交易日 9:25–9:40，如果还有股票停在提醒区，会再汇总发一次。最近 6 小时已经单独发过的股票，这次汇总会跳过。
- 其余时间可以在页面里点「立即检查并推送」。这次会按当前价把还在提醒区里的股票再发一遍。
- 打开页面只会刷新报价，不会因此发微信。

## 跑起来

需要 Node.js 20 或更高。

双击 `start.bat`，或在项目目录执行：

```bash
npm start
```

浏览器打开 http://127.0.0.1:8787 。窗口关了，提醒就停。

手机和电脑在同一个 Wi-Fi 时，用启动日志里的局域网地址打开。公网访问前，先在设置里加一个访问口令。

A 股、场内基金输入 6 位代码，北交所同样是 6 位，港股输入 `hk00700` 或 5 位代码。

## 微信怎么收到

小程序订阅消息要每次点授权，个人用很容易漏。这里用 [PushPlus](https://www.pushplus.plus)：微信扫码登录，复制 token，填到设置里，点「发一条测试」。也可以改用 [Server酱](https://sct.ftqq.com)。

没配推送时，触发的提醒仍会记在「记录」里，只是不会进微信。

## 小程序

1. 安装微信开发者工具，导入本仓库的 `miniprogram` 目录。没有 AppID 时用测试号。
2. 详情里勾选「不校验合法域名」。
3. 设置页的服务器地址：模拟器用 `http://127.0.0.1:8787`；真机预览改成电脑的局域网地址。
4. 正式发布需要已备案的 HTTPS 域名，并配到小程序的 request 合法域名。在那之前，手机浏览器打开同一个服务就能记账和收微信。

## 数据

持仓、设置和提醒记录都在 `data/db.json`，已从 git 忽略。删掉这个文件就会清空。PushPlus token 也在里面，不要把这个文件传给别人。

提醒记录不按天数过期。文件里最多留最新的 200 条，再新的一条会挤掉最旧的。页面上的「记录」只显示其中最新的 80 条。持仓不会因为记录被挤掉而删除。微信里已经发出去的消息留在微信聊天记录里，不受这个条数限制。
